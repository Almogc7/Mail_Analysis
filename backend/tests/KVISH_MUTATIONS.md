# Kvish mutation analysis (sanitized fixture only; the hold-out is never used)

Generated by `python -m tests.kvish_mutations [--ablate-seeds]`; pinned by `tests/test_kvish_mutations.py`. Each row edits
the PARSED message and re-runs the whole pipeline in STRICT and CONFIGURED mode. **Nothing was changed in response to these
results; this reports what the verdict depends on.** The Return-Path, the rest of the Received chain and the body text are
untouched, so "sender" mutations change only the From identity.

Axes: origin (the original local submission on the hosting box, or the first hop replaced by authenticated SMTP) x sender
(as is, an unrelated hosting domain, a freemail address) x the 8 subsets of {remove the display name, replace the SendGrid
CTA with a direct link to an unrelated host, drop the hot-linked images} = 48 rows.

## What the verdict depends on

* **Reached >= SUSPICIOUS:** with seeds present 32/48, with seeds ablated 29/48, identically in STRICT and CONFIGURED (the
  fixture carries no trusted authentication result, so trust mode is irrelevant here).
* **While the first hop is a local submission (24 rows), 21 still flag.** The three that do not are the ones with every
  content feature removed: only `S2` (sender family) remains, one family, inconclusive. Any single remaining link or claim
  signal is enough. **Who the sender appears to be (unrelated hosting domain, freemail) never changes the verdict** in this
  group, because the load-bearing sender evidence is the origin hop, not the From address.
* **Replace the origin hop with authenticated SMTP (24 rows) and only 8 (ablated) / 11 (seeds present) flag.** The local
  submission hop is the single most load-bearing signal: without it the verdict needs two of the link/claim signals to
  survive, and removing the display name alone is already enough to fall to inconclusive. With every content feature removed
  AND an authenticated origin, no structural signal remains at all.
* **Consequence for an attacker, stated plainly:** a lure that arrives by authenticated submission (a compromised mailbox, a
  rented ESP account) and keeps a clean display name, a direct link and its own images leaves nothing for the structural
  families to see. This is the class the design does not target (README, "What the detectors can and cannot see").
